Filament Menu Manager is structured as a standard Laravel/Filament package. The core responsibility of the package is to allow administrators to define custom location-based navigation hierarchies (menus) and map them to custom URLs or polymorphic Eloquent models.

## Data Flow

1. Admin registers the plugin in their `PanelProvider` calling fluent methods (`locations()`, `modelSources()`).
2. At boot, locations and models are merged with config and registered in the `MenuManager` singleton.
3. Configured locations are synchronized to the database.
4. When access to `MenuManagerPage` occurs, users select/create a Menu.
5. `MenuPanel` allows adding new custom items or Eloquent items to `MenuBuilder`.
6. Reordering triggers `updateOrder` (drag-and-drop) or button actions, saving the hierarchical nested structure back to the database.
